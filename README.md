# 🤖 Суверенный ИИ-оркестратор и защищённый MCP-сервер склада (v6.0)

Официальный репозиторий с исходным кодом к книге **«ИИ-агенты на Python: от прототипа до автономных систем»** (Главы 9–10).

Проект представляет собой изолированный **Model Context Protocol (MCP)** сервер стандарта v2.x, упакованный в **Docker-контейнер**, и автономный Python-оркестратор, работающий через шлюз **OpenRouter** с двухтактным контролем качества (**ИИ-судья**).

## 🏗 Архитектура комплекса

```text
┌─────────────────────────────┐      stdio (JSON-RPC 2.0)      ┌──────────────────────────────┐
│    orchestrator.py (Хост)   │ ◄────────────────────────────► │  Docker: bob-warehouse-mcp   │
├─────────────────────────────┤                                ├──────────────────────────────┤
│ • OpenRouter (Tool Loop)    │       Volume Mount (-v)        │ • server.py (MCP SDK v2.x)   │
│ • ИИ-судья (Llama-3.3-70B)  │        ┌──────────────┐        │ • DevSecOps SQL-фильтры      │
│ • Контроль галлюцинаций     │        │   ./data/    │        │ • RAG-поиск по регламентам   │
└─────────────────────────────┘        │ • warehouse.db        │ • JSON-аудит (sys.stderr)    │
                                       │ • regulations.json    └──────────────────────────────┘
                                       │ • audit.log  │
                                       └──────────────┘
```

### Ключевые особенности
* **Изоляция среды (Docker + WSL 2):** Микросервис запускается локально с миллисекундным откликом, без сетевых туннелей и открытых портов.
* **DevSecOps-защита периметра:** Упреждающая блокировка деструктивных SQL-инъекций (`DROP`, `DELETE`, `ALTER` и др.) и строгий режим чтения без фиксации изменений (`commit()`).
* **Независимость от вендора (Vendor-Agnostic):** Суверенный диспетчер `orchestrator.py` заменяет ручной интерфейс чата, позволяя переключать любые модели через OpenRouter.
* **Промышленный мониторинг (LLMOps):** Разделение потоков `stdout` (протокол) и `stderr` (машиночитаемый JSON-журнал событий `audit.log`).

## 🚀 Быстрый старт (Локальное развёртывание в 2 шага)

### Предварительные требования
* Установленный **Python 3.11+** и **Docker Desktop** (должен быть запущен в фоне).
* API-ключ от платформы [OpenRouter](https://openrouter.ai).

### Шаг 1. Подготовка данных и сборка Docker-образа
Клонируйте репозиторий, сгенерируйте локальные хранилища данных и соберите изолированный контейнер:

```bash
# 1. Клонируйте репозиторий проекта
git clone https://github.com
cd industrial-ai-agents-python

# 2. Сгенерируйте физическую БД SQLite и файл регламентов RAG в папке data/
python init_db.py
python init_docs.py

# 3. Соберите производственный Docker-образ
docker build -t bob-warehouse-mcp .
```

### Шаг 2. Запуск суверенного оркестратора
Установите клиентские зависимости на хост-машине, задайте API-ключ и запустите автономный конвейер:

**Для Windows (PowerShell):**
```powershell
pip install openai "mcp>=2.0.0"
\$env:OPENROUTER_API_KEY="sk-or-v1-ваш-секретный-ключ"
python orchestrator.py
```

**Для Linux / macOS (Bash/Zsh):**
```bash
pip install openai "mcp>=2.0.0"
export OPENROUTER_API_KEY="sk-or-v1-ваш-секретный-ключ"
python orchestrator.py
```
