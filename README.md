\## Что внутри репозитория



\* \*\*`Industrial-AI-agent.ipynb`\*\* — сквозной практический блокнот (Главы 1–7): пошаговая сборка ИИ-комплекса от базовых контрактов Pydantic и конечных автоматов Outlines до резидентного поиска RAG, двухтактного надзора через ИИ-судью (OpenRouter), трёхэшелонной защиты SQLite и MCP-сервера.

\* \*\*`Individual-Code-Fragments.ipynb`\*\* — вспомогательный блокнот с изолированными экспериментами и тестами моделей.

\* \*\*`listings/`\*\* — все листинги кода из книги в виде отдельных готовых `.py`-файлов (без сокращений):

&#x20; \* `listings/main\_project/` — блоки кода основного конвейера (`block\_01.py` — `block\_34.py`, включая литерные блоки `22A`, `22B`, `25A`).

&#x20; \* `listings/fragments/` — отдельные тестовые фрагменты (`fragment\_01.py` — `fragment\_05.py`).

\* \*\*Производственный Docker-комплекс (Главы 9–10):\*\*

&#x20; \* `init\_db.py` и `init\_docs.py` — скрипты генерации физической БД SQLite (`warehouse.db`) и базы корпоративных регламентов (`regulations.json`) в папке `data/`.

&#x20; \* `server.py` — единый производственный MCP-сервер (стандарт v2.x, транспорт `stdio`, JSON-аудит в `sys.stderr` и `audit.log`).

&#x20; \* `Dockerfile` — декларативная инструкция сборки изолированного Linux-образа.

&#x20; \* `orchestrator.py` — автономный Python-оркестратор с циклом вызова инструментов через OpenRouter и финальной проверкой ответов ИИ-судьёй.

&#x20; \* `web\_demo.py` — локальная веб-витрина проекта на базе Gradio.

\* \*\*`mcp\_bridge.py`\*\* — асинхронный мост-ретранслятор (`stdio` ↔ `SSE`) из Главы 8 для экспериментов с сетевыми туннелями.

\* \*\*`hf\_deploy/`\*\* — готовый комплект файлов (`app.py`, `server.py`, `init\_db.py`, `init\_docs.py`, `requirements.txt`) для публикации облачной демо-витрины на платформе \*\*Hugging Face Spaces\*\*.

\## Быстрый старт: запуск производственного комплекса в Docker



\### 1. Подготовка данных на локальном диске

Склонируйте или скачайте файлы репозитория в рабочую папку (например, `C:\\mcp\_project`) и сгенерируйте локальные хранилища в подпапке `data/`:



```bash

python init\_db.py

python init\_docs.py

```



\### 2. Сборка Docker-образа

Убедитесь, что запущен \*\*Docker Desktop\*\*, и выполните сборку образа (не забудьте точку в конце команды):



```bash

docker build -t bob-warehouse-mcp .

```



\### 3. Запуск автономного оркестратора (Глава 10)

Установите клиентские библиотеки и задайте ваш API-ключ OpenRouter в переменных среды:



```bash

pip install openai "mcp>=2.0.0" --upgrade

```



\*\*Windows (PowerShell):\*\*

```powershell

\\$env:OPENROUTER\_API\_KEY="sk-or-v1-ваш-ключ"

python orchestrator.py

```



\*\*Linux / macOS:\*\*

```bash

export OPENROUTER\_API\_KEY="sk-or-v1-ваш-ключ"

python orchestrator.py

```
